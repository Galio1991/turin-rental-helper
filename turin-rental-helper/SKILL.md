# 都灵租房助手

根据用户需求多区域广撒网搜索、动态权重评分推荐的租房工作流。

## 核心改进

### 1. 多区域并行搜索
不再只搜一个区域，而是同时搜索多个安全区域：
- 根据用户需求动态确定搜索区域列表
- 优先搜索用户指定区域
- 同时搜索其他安全区域（安全评分≥6）

### 2. 动态权重调整
权重不再写死，根据用户偏好动态调整：
- 用户可自定义各维度权重
- 根据用户强调的重点调整权重
- 综合评分考虑多个维度

### 3. 灵活筛选策略
不轻易排除区域，而是综合评分后排序：
- 只排除真正危险的区域（Aurora、Barriera di Milano等）
- 其他区域通过评分排序
- 房型、家具等作为软性筛选

## 工作流程

### 1. 收集用户需求

从用户输入中提取：
- 预算范围（月租上限）
- 房型偏好（studio/合租单间/整套）
- 位置偏好（靠近哪所学校）
- 特殊要求（全包/独立供暖/空调/家具）
- **重点强调的因素**（用于动态调整权重）

### 2. 动态确定搜索区域

根据用户偏好和区域数据，动态确定搜索区域：

**搜索策略**：
1. 用户指定的优先区域（如有）
2. 其他安全区域（安全评分≥6）
3. 根据距离和性价比排序

**默认搜索区域**（安全+性价比）：
- Cit Turin - 安全8.5，靠近学校
- Cenisia - 安全7.0，性价比高
- San Donato - 安全7.0，价格适中
- Crocetta - 安全9.0，高档
- Centro - 安全7.5，便利
- Borgo San Paolo - 安全6.5，学生区

### 3. 多区域并行爬取

使用Firecrawl同时爬取多个区域：
- Immobiliare.it
- Idealista.it

每个区域独立爬取，汇总所有房源。

### 4. 动态权重评分

根据用户偏好动态计算评分：

**权重配置**：
```python
weights = {
    'price': 0.25,      # 价格
    'safety': 0.15,     # 安全性
    'distance': 0.15,   # 距离学校
    'transport': 0.20,  # 公共交通便利性
    'location': 0.10,   # 位置（综合）
    'facility': 0.15    # 设施
}
```

**公共交通评分因素**：
- 地铁站距离（步行分钟数）
- 公交线路数量
- 有轨电车覆盖
- 夜间公交服务
- 火车站可达性

**用户可调整权重**：
- 如果用户强调"便宜"，提高price权重
- 如果用户强调"安全"，提高safety权重
- 如果用户强调"近"，提高distance权重
- 如果用户强调"交通便利"，提高transport权重

### 5. 综合排序推荐

整合所有区域的房源，按综合评分排序：
- 不轻易排除区域
- 房型、家具等作为软性筛选
- 综合考虑所有维度
