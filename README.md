# 都灵租房助手 (Turin Rental Helper)

为前往意大利都灵留学的中国学生提供个性化租房服务的 Claude Code Skill。

## 核心功能

- 🔍 **多区域广撒网搜索** - 同时搜索多个安全区域
- ⚖️ **动态权重调整** - 根据用户偏好动态调整评分权重
- 🚇 **公共交通评分** - 地铁、公交、有轨电车全覆盖评估
- 📊 **综合分析推荐** - 整合所有区域房源，综合排序推荐
- 🛡️ **安全区域筛选** - 自动排除危险区域，优先推荐安全区域

## 环境要求

- Python 3.7+
- Claude Code CLI
- numpy

## 安装

```bash
pip install numpy
cp -r turin-rental-helper ~/.claude/skills/
```

## 使用

在Claude Code中输入租房需求，例如：

```
我需要找450欧以内的合租单间，最好有集中供暖，靠近都灵理工
```

Skill会自动：
1. 分析需求，动态调整权重
2. 确定多个搜索区域
3. 多区域并行爬取房源
4. 动态权重评分
5. 综合排序输出推荐（覆盖多个区域）

## 动态权重调整

根据用户强调的重点，自动调整评分权重：

| 用户重点 | 价格 | 安全 | 距离 | 交通 | 位置 | 设施 |
|----------|------|------|------|------|------|------|
| 默认 | 25% | 15% | 15% | 20% | 10% | 15% |
| 强调便宜 | 40% | 15% | 10% | 15% | 10% | 10% |
| 强调安全 | 20% | 35% | 10% | 15% | 10% | 10% |
| 强调近 | 20% | 15% | 30% | 15% | 10% | 10% |
| 强调交通 | 20% | 15% | 15% | 30% | 10% | 10% |

**公共交通评分因素**：
- 🚇 地铁站距离（步行分钟数）
- 🚌 公交线路数量
- 🚃 有轨电车覆盖
- 🌙 夜间公交服务
- 🚂 火车站可达性
