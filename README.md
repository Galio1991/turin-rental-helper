# 都灵租房助手 (Turin Rental Helper)

为前往意大利都灵留学的中国学生提供个性化租房服务的 Claude Code Skill。

## 核心功能

- 🔍 **多区域广撒网搜索** - 同时搜索多个安全区域
- ⚖️ **动态权重调整** - 根据用户偏好动态调整评分权重
- 📊 **综合分析推荐** - 整合所有区域房源，综合排序推荐
- 🛡️ **安全区域筛选** - 自动排除危险区域，优先推荐安全区域

## 环境要求

- Python 3.7+
- Claude Code CLI
- numpy

## 安装

```bash
pip install numpy
cp -r turin-rental-helper ~/.claude/skills/
```

## 使用

在Claude Code中输入租房需求，例如：

```
我需要找450欧以内的合租单间，最好有集中供暖，靠近都灵理工
```

Skill会自动：
1. 分析需求，动态调整权重
2. 确定多个搜索区域
3. 多区域并行爬取房源
4. 动态权重评分
5. 综合排序输出推荐（覆盖多个区域）

## 动态权重调整

根据用户强调的重点，自动调整评分权重：

| 用户重点 | 价格权重 | 安全权重 | 距离权重 | 位置权重 | 设施权重 |
|----------|----------|----------|----------|----------|----------|
| 默认 | 30% | 15% | 10% | 25% | 20% |
| 强调便宜 | 45% | 15% | 10% | 15% | 15% |
| 强调安全 | 20% | 35% | 10% | 25% | 10% |
| 强调近 | 25% | 15% | 30% | 20% | 10% |

## 区域安全指南

### ✅ 安全区域（推荐搜索）

| 区域 | 安全评分 | 距离理工 | 特点 |
|------|----------|----------|------|
| Crocetta | 9.0 | 2.0km | 最安全，高档 |
| Cit Turin | 8.5 | 0.5km | 学生首选 |
| Borgo Po | 8.0 | 2.5km | 环境优美 |
| Centro | 7.5 | 1.5km | 市中心 |
| Cenisia | 7.0 | 1.0km | 性价比高 |
| San Donato | 7.0 | 1.5km | 价格适中 |

### ⚠️ 危险区域（自动排除）

| 区域 | 安全评分 | 原因 |
|------|----------|------|
| Aurora | 4.0 | 移民多，犯罪率高 |
| Barriera di Milano | 3.5 | 犯罪率最高 |
| Porta Palazzo | 4.5 | 犯罪率较高 |

## 输出格式

```

### 1. [房源标题]（网址）
- 价格：€XXX/月
- 位置：区域名称（安全评分X/10）
- 距离学校：Xkm，自行车X分钟
- 设施：暖气、空调、家具
- 综合评分：X/10
- 推荐理由：XXX
```
